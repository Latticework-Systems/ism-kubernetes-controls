# Security Policy

## Supported versions

Security fixes are applied to the latest published release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed secret. Email **tim@latticeworksystems.com.au** with the affected file or policy, reproduction steps, impact, and any suggested mitigation. Maintainers will acknowledge the report and coordinate disclosure directly with you.

Non-sensitive policy correctness and mapping issues may be reported through normal GitHub issues.
